# Changelog

## [1.49.0] - 2026-09-01

### Added

- **Undo for Deleted Transactions** - Accidentally deleted a transaction? An undo toast appears at the bottom of the screen, giving you a chance to restore it. Works for both single deletions and bulk deletions.

### Fixed

- **Toast Position** - Undo toast now appears at the bottom of the screen for better visibility and accessibility
- **Firestore Error Messages** - Raw `firestore/*` error messages are no longer shown to users
- **Category Label Mutation** - Fixed a bug where category labels could be accidentally mutated
- **UI Fixes** - Multiple UI fixes and polish across the application
- **General Bug Fixes** - Various stability improvements

### Changed

- **Cloud Sync Reliability** - All domain services now use `pushToCloudSafe` for safer and more reliable cloud synchronization
- **Code Quality** - Refactored code following best practices and removed duplicate subsystems
