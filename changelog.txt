# Changelog

## [1.47.0] - 2026-08-22

### Added

- **Change Date in Bulk Edit** - You can now reschedule multiple selected transactions at once from the bulk edit menu
- **Edit Highlight Animation** - Edited transactions briefly pulse green so you can instantly spot what just changed

### Fixed

- **Notes Now Save on New Transactions** - Notes typed while adding a transaction were silently discarded; they now persist exactly like they do when editing
- **Dashboard Account Filter Self-Heals** - If the selected account is deleted, the filter automatically resets to "All Accounts", keeping the displayed account name and balance in sync
- **Savings Goals** - Several goal-related bugs fixed
- **Empty States** - Empty-state screens now use the correct background color
- **Highlighting** - Fixed transaction highlight behavior in the list

### Changed

- **Goal Edit Form Layout** - Field labels now sit beside their inputs again, restoring the compact inline form instead of tall stacked fields

### Security & Maintenance

- CI workflows now target the main branch and pin GitHub Actions to immutable commit SHAs
- Security hardening (G1) and reconciled security documentation claims
- Dashboard filters are persisted only after a transaction is successfully saved
- Safer rollback handling when moving transaction dates creates ghost entries
- Corrected financial-planning formula descriptions
- Test logic updates and lint/format cleanup
