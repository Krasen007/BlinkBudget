### Summary v1.44

- Quarter-based navigation added to reports for faster period switching
- Transactions can now be saved with Enter and duplicated with a long-press
- Category reordering now respects filtered views
- New eye icon reveals password fields; missing empty states fixed
- Privacy policy and terms of service are now served from the public directory

---

### Added

- **Quarter navigation in reports** — Quickly jump between Q1, Q2, Q3, and Q4 periods when viewing reports.
- **Enter to save in edit mode** — Pressing Enter while editing a transaction now automatically saves it, matching the behavior in ReportsView.
- **Copy transactions** — Long-press (hold) over any transaction in the dashboard to duplicate it instantly.
- **Password visibility toggle** — An eye icon has been added to password fields so you can reveal or hide the text as you type.

### Changed

- **Category reordering respects filters** — Arrow-move now reorders only the currently visible (filtered) category list and persists that order. Previously it reordered across all categories (including hidden types), so moves inside a filtered view often had no visible effect.
- **Landing page updated** — Refreshed content and layout on the landing page.
- **Documentation moved to public** — `docs/privacy-policy.md` and `docs/terms-of-service.md` have been moved to `public/`. They are now copied to `dist/` during build and served publicly at `/privacy-policy.md` and `/terms-of-service.md`.

### Fixed

- **Missing empty state** — Restored the empty state UI that was previously missing.
- **Font preload warnings** — Removed explicit `rel="preload"` font tags from `index.html` since fonts are loaded via the Google Fonts stylesheet and the preload hints were not being used early enough.

### Screenshots

- Captured crisp, high-resolution screenshots of all major application views using an automated browser agent on the live dev server.
