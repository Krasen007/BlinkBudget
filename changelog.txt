### Summary v1.45

This release focuses on enhanced validation, improved investment tracking, and bug fixes across the application.

---

### Added

- **Enhanced transaction validation** — Improved validation logic for all transaction types to prevent data inconsistencies and ensure data integrity.
- **Refund transaction labels** — Added support for tags on refund transactions, completing the labeling feature across all transaction types.
- **Cancel button in Goals section** — Added a cancel button to make goal management more intuitive and reduce accidental actions.

### Changed

- **Investment section simplified** — Rewrote the advanced features to be read-only by default, with a clearer focus on portfolio overview and essential functionality.
- **Labels feature** — Improved label system with better organization and management.
- **Documentation updates** — Verified implementation of audit documents and updated README with the latest features.

### Fixed

- **Validation fixes** — Resolved several edge cases in transaction validation that could cause issues with certain data combinations.
- **False statement handling** — Fixed incorrect statements in validation and reporting logic.
- **DODCS validator fix** — Corrected issues in the data validation system for better accuracy.
