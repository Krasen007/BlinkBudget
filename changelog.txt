BlinkBudget Changelog

=== Recent Updates ===

• Sankey chart improvements: Made responsive and consistent with other Insights charts. Reduced minimum height to 360px, removed heavy label outlines, and added keyboard-focusable nodes labeled with category and percentage. Tooltips now appear positioned from node bounds.

• Drill-down enhancements: Spending graph (month-by-month history strip) now appears when drilling into tags from Reports or account types from Explore Accounts.

• Spending spike insights: Each purchase is now judged against its own category (mean + 1.5σ, minimum 5 expenses), so a €15.83 lunch isn't marked 'unusually large' just because the month also has €1.65 bus tickets. Single-purchase categories no longer show '100.0% of category spending.'

• Category drill-downs: Clicking a category opens a history strip showing 12-month spending trends. Tapping a month re-filters the transaction list using the same state as the Spent-card arrows. Account filter is honored while period filters are deliberately bypassed.

• Data recovery: Page to read BlinkBudget data from this browser's local storage without loading the app or connecting to Firebase.

• Category reorder: Custom category sorting now correctly syncs to the cloud. reorder() writes sortOrder (0, 1, 2…) plus updatedAt, and full item array including sortOrder is sent to Firestore.

• Dashboard performance: Bars are now DOM buttons scaled by CSS custom properties instead of Chart.js canvas, so the dashboard doesn't wait on the lazy chart chunk.

• Tooltip improvements: Category names inserted via textContent in CashFlowSankeyCard.js. Refund-only categories now appear as inflows within refund transactions' periods.

• Regression coverage added for sankey-layout-utils, CashFlowSankeyCard, aggregation rules, and DashboardView integration tests.

• Lint warnings fixed.

=== Earlier Updates ===

• Cash Flow matching: Flow adjusted to match the provided chart format.

• Tag label fix: History label corrected when drilling into a tag from Reports.

• Branch merge: Master branch merged with all accumulated changes.

• Initial setup: BlinkBudget data recovery page created. Reads only this browser profile's local storage data; does not load the app or connect to Firebase.
# Changelog

## [1.51] - 2026-11-03

### Added

- **Category drill-downs with 12-month history** - Tapping a category in the dashboard opens a detailed view showing how spending in that category moved over the last 12 months. The view uses fast CSS bars instead of Chart.js so it loads instantly. Tapping a month re-filters the transaction list to that period.
- **Smarter spending spike insights** - Unusual spending is now detected per category, so a €15 lunch isn't flagged just because the same month includes cheap bus tickets. Categories with only one purchase no longer show misleading "100% of category spending" messages. Uses statistical detection (average plus 1.5x standard deviation) with a minimum of five expenses per category.
- **Cloud sync for category reordering** - Reordering categories now persists sort order to Firestore, so your custom category order syncs across devices.

### Fixed

- **Category roll-up labels** - Cross-category spending summaries now name the actual purchase (note + category) instead of showing only the category name.
- **Lint warnings resolved** - Cleaned up ESLint warnings across the codebase.

### Under the hood

- Category drill-down includes component tests and a DashboardView integration test covering month placement, viewed-month anchoring, and month tapping.
- Spending spike detection includes regression tests for false alarms, single-purchase categories, genuine outliers, roll-up labeling, and ghost exclusion.
